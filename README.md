# 管球平衡控制

基于 ROS 2 的单自由度管球平衡控制练习项目，用于学习仿真、PID/LQR 与后续强化学习控制。来源于26年电子设计竞赛H题。

## 目标

管子一端固定，可绕固定端转动；球沿管轴运动。控制器驱动管子，使球保持在目标位置，并抵消管子固定端加速等因素产生的等效惯性力。

第一版使用仿真信息源：球位置以 50 FPS 输出，固定延迟 2 ms。小车不是被控对象；其启动、行驶、转弯和停车的影响统一抽象为固定端基座加速度。

## 架构

```text
干扰源 ── 基座加速度 ──► 管球系统 ── 真实状态 ──► 信息源 ── 测量值 ──► 控制器
                              ▲                                           │
                              └──────────── 管子控制命令 ───────────────────┘
```

| 功能包 | 核心节点 | 职责 |
| --- | --- | --- |
| `ball_tube` | `plant_node` | 管球动力学、管子执行器、约束与真实状态；后续可替换为 Gazebo。 |
| `sensing_info` | `sensor_node` | 生成视觉、管角和 IMU 测量，管理频率、延迟、噪声和丢帧。 |
| `tube_controller` | `controller_node` | PID、LQR 与未来的强化学习策略；仅依据测量信息输出管子命令。 |
| `disturbances_sim` | `disturbance_node` | 随机扰动、预设小车轨迹和实测加速度回放。 |

控制器不得直接读取仿真真值或干扰真值；所有可观测信息均应由 `sensing_info` 提供。



## 开发

项目使用 `ament_cmake` 和 `rclcpp` 开发。构建前需加载本机的 ROS 2 环境：

```bash
source /opt/ros/${ROS_DISTRO}/setup.bash
colcon build --symlink-install
source install/setup.bash
```

开发顺序：先用真实状态验证动力学和 PID/LQR；再接入延迟信息源与状态估计；随后加入随机和车辆加速度扰动；最后在不改变节点接口的前提下尝试强化学习控制器。
